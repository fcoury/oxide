### Storage migration required

This release introduces `oxide:jsonb:v2` to preserve BSON document field order. Existing version-one collections are refused without modification. Back up the original database, export through the original Oxide binary, and import into a separate database with this version. Previously lost field order cannot be recovered by relabeling tables. See the [migration instructions](https://github.com/fcoury/oxide/blob/v0.2.0/docs/compatibility.md#storage-version-and-legacy-databases).

The release also includes the upstream compatibility baseline: all 56 selected MongoDB tests are required release checks. This selected suite does not establish full MongoDB compatibility.
